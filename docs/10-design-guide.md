# SwimVault 디자인 가이드 (Design Guide)

> 살아있는 문서. UI/UX를 바꿀 때 **먼저 이 문서를 보고, 바꾼 뒤 이 문서를 갱신**한다.
> 토큰은 `frontend/src/styles.css`의 `:root`에 코드로 박혀 있다(문서 = 코드 동기화).

문서 버전: v1.0 · 최초 작성: 2026-06-19

---

## 1. 디자인 철학

벤치마크는 **Meet Mobile**(수영계 표준 결과 앱). 교훈: *"누구나 쉽게 탐색"이 최고의 강점,
디자인 폴리시보다 명료함이 우선*. SwimVault는 **그 단순함을 유지하되 더 현대적·직관적**으로.

| # | 원칙 | 의미 |
|---|------|------|
| D1 | **명료함 > 화려함** | 0.01초가 의미 있는 데이터. 숫자·추세가 한눈에. 장식은 최소. |
| D2 | **단일 강조색** | 주색(아쿠아 블루) 하나로 액션·선택·강조를 통일. 색을 늘리지 않는다. |
| D3 | **데이터는 모노스페이스 정렬** | 기록 시간은 `tabular-nums`로 자릿수 정렬 → 비교 쉬움. |
| D4 | **그래프는 방향이 보이게** | "위로 갈수록 빠름" 등 축 의미를 명시. 격자·면적으로 추세 강조. |
| D5 | **토큰만 사용** | 색/간격/반경은 CSS 변수(`var(--…)`)로만. 하드코딩 금지. |
| D6 | **터치 우선** | 터치 타깃 ≥ 40px, 하단 내비, `env(safe-area-inset-*)` 존중. |

---

## 2. 색상 토큰 (Color)

주색은 **아쿠아 블루**(수영/물의 정체성). 보조·의미색은 최소로 절제.

| 토큰 | 라이트 | 용도 |
|------|--------|------|
| `--c-primary` | `#0b74d1` | 주 액션, 선택, 링크, 강조 |
| `--c-primary-strong` | `#075aa8` | 눌림/진한 상태 |
| `--c-primary-soft` | `#e8f1fb` | 선택 행 배경, 옅은 강조 |
| `--c-accent` | `#13b5a6` | 보조 강조(드물게) |
| `--c-success` | `#16a34a` | 향상(빨라짐), 확정 |
| `--c-pb` / `--c-pb-ink` | `#f5b301` / `#5a4500` | 개인기록(PB) 뱃지 |
| `--c-warn` | `#e0892a` | 주의 |
| `--c-danger` | `#dc2626` | 오류, 저신뢰, 로그아웃 |
| `--c-bg` | `#f6f8fa` | 앱 배경 |
| `--c-surface` | `#ffffff` | 카드/표면 |
| `--c-border` | `#e6e9ee` | 경계선 |
| `--c-text` | `#14181d` | 본문 |
| `--c-text-2` | `#5b6571` | 보조 텍스트 |
| `--c-text-3` | `#919aa6` | 비활성/메타 |

다크 모드는 `@media (prefers-color-scheme: dark)`에서 **같은 토큰을 재정의**한다.
→ 컴포넌트는 토큰만 쓰므로 자동으로 다크 대응.

### 등급(Standard) 히트맵 — 단색 강도 램프
무지개색 대신 **주색의 명도 단계**(연함→진함 = 느림→빠름)로 통일 → 산만함 제거, 진행감 직관화.
`--tier-1`(B, 연함) … `--tier-6`(AAAA, 진함). B/BB는 어두운 글자, A 이상은 흰 글자.

---

## 3. 타이포그래피 (Type)

- 글꼴: 시스템(`system-ui`). 별도 웹폰트 없음(성능·로딩).
- 기록 시간/숫자: **`font-variant-numeric: tabular-nums`** 필수(D3).
- 위계: h1 1.3rem / h2 1.2rem / h3 1.0rem / 본문 0.9rem / 메타 0.78rem. 가중치 600~800로 강약.

---

## 4. 간격·형태 (Spacing & Shape)

| 토큰 | 값 | 용도 |
|------|----|------|
| `--r-sm` / `--r-md` / `--r-lg` / `--r-pill` | 6 / 10 / 14 / 999px | 반경 |
| `--sp-1`…`--sp-4` | 4 / 8 / 12 / 16px | 간격 스케일 |
| `--shadow-card` | 옅은 그림자 | 카드 부양(과하지 않게) |

카드는 `--c-surface` + `--c-border` 1px + `--r-lg`. 그라데이션은 지양(D1), 필요 시 1곳만.

---

## 5. 컴포넌트 패턴

- **버튼**: `.primary`(주색 채움) / `.seg`(세그먼트 토글) / `.link`(텍스트) / `.danger`.
- **칩**: PB(`--c-pb`), 나이대(`age-chip`, 주색), 등급(`tier-*`), 역할(`role-*`).
- **표(베스트타임/나이그룹)**: 헤더는 `--c-text-3` 소형 대문자 느낌, 행 구분선 `--c-border`,
  선택 행 `--c-primary-soft`. 시간 열은 tabular-nums + 굵게.
- **하단 내비**: 4탭, 활성 = 주색. 아이콘+라벨.

---

## 6. 그래프 가이드 (D4 — 가장 중요)

기록 화면은 그래프가 많다. **직관성**이 핵심.

- **진척 그래프(ProgressionChart)**
  - 방향 명시: 좌상단에 "빠를수록 위 ↑" 라벨. y축은 빠른 기록이 위로.
  - **수평 격자선**(옅게) 3~4개로 값 비교 보조.
  - 선 아래 **면적 그라데이션**으로 추세를 한눈에.
  - 점은 충분히 크게(r≥4), **PB는 금색 링**으로 구별. 각 점에 `<title>`(날짜·기록) 제공.
  - 시작/끝 날짜·기록을 그래프 하단에 캡션.
- **공통**: 외부 차트 라이브러리 금지(번들 경량) → SVG 직접 그림.
- 색: 선·점은 `--c-primary`, PB는 `--c-pb`, 향상 텍스트는 `--c-success`.

---

## 7. 접근성 (A11y)

- 색만으로 의미 전달 금지(향상은 색+▼아이콘, 저신뢰는 색+⚠).
- 명도 대비: 본문 텍스트 ≥ 4.5:1. 등급 칩 글자색은 배경 명도에 맞춰 전환.
- 모든 인터랙티브 요소는 키보드 접근(역할·`aria-*`), 터치 타깃 ≥ 40px.

---

## 8. Do / Don't

- ✅ 토큰 사용, 단일 강조색, tabular-nums, 그래프 방향 라벨.
- ❌ 색 하드코딩, 무지개 팔레트, 의미를 색에만 의존, 과한 그라데이션/그림자.
